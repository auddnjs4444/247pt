# 이미지 폴더

이 폴더에 아래 파일명 그대로 사진을 넣으면 자동으로 사이트에 반영됩니다.
**파일이 없으면 어두운 그라데이션 플레이스홀더가 대신 표시되므로 사이트가 깨지지 않습니다.**

| 파일명 | 쓰이는 곳 | 권장 크기 / 비율 |
|---|---|---|
| `hero.jpg` | 첫 화면 전체 배경 | 2400 × 1600 (가로) |
| `about.jpg` | 소개 섹션 세로 이미지 | 1200 × 1500 (4:5 세로) |
| `zone-free.jpg` | 프리 웨이트 존 | 1600 × 1280 (5:4) |
| `zone-cardio.jpg` | 유산소 존 | 1600 × 1280 (5:4) |
| `zone-machine.jpg` | 머신 웨이트 존 | 1600 × 1280 (5:4) |
| `zone-24h.jpg` | 24시간 운영 | 1600 × 1280 (5:4) |
| `pt.jpg` | PT 섹션 배경 | 2400 × 1400 (가로) |
| `gallery-1.jpg` ~ `gallery-5.jpg` | 갤러리 슬라이드 | 1600 × 1200 (4:3) |
| `map.jpg` | 오시는 길 지도 이미지 (네이버 지도 캡처 등) | 1200 × 900 |
| `og.jpg` | 카카오톡·SNS 공유 썸네일 | 1200 × 630 (고정) |
| `apple-touch-icon.png` | iOS 홈화면 아이콘 | 180 × 180 |

## 팁
- 첫 화면(`hero.jpg`)은 어두운 사진일수록 노란색 글씨가 잘 보입니다.
- 용량은 장당 **300KB 이하**로 압축하는 걸 권장합니다 (squoosh.app 등).
- `.webp`로 넣고 싶다면 `index.html`의 `data-img="..."` 경로만 바꾸면 됩니다.
